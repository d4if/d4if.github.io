Ekosistem Tanda Tangan Digital

Dokumen resmi program studi ditandatangani dengan algoritma Ed25519 (PASETO v4.public) agar keasliannya dapat diperiksa langsung di browser tanpa server perantara.

Repositori Sign Lihat Tata Cara Signing

Tata Cara Signing Dokumen

Panduan menandatangani dokumen PDF atau berkas resmi dengan CLI sign agar QR Code langsung tervalidasi di repo.if.ulbi.ac.id/validate/ tanpa memasukkan kunci publik secara manual.

  1. 1. Pasang CLI sign di Laptop

    Unduh Manual

    Jalankan satu baris perintah berikut sesuai sistem operasi Anda untuk mengunduh binary resmi, memverifikasi checksum SHA-256, dan memasangnya langsung tanpa perlu kompilasi.

    macOS & Linux (Terminal / Shell) 
    curl -fsSL https://repo.if.ulbi.ac.id/install.sh | sh
    Windows (PowerShell) 
    irm https://repo.if.ulbi.ac.id/install.ps1 | iex

    Setelah terpasang, cek kesiapan CLI dengan menjalankan sign --version.

  2. 2. Siapkan Kunci Penanda Tangan

    Untuk dokumen resmi Prodi D4TI ULBI, gunakan berkas signing.key resmi yang dipasangkan dengan kunci publik tertanam (kid: d4if-ulbi-2026). Jika membuat pasangan kunci baru untuk pengujian atau unit mandiri:

    sign keygen --secret-out signing.key --public-out verifying.key

    Simpan signing.key secara privat dan jangan pernah dikirim ke repositori publik.

  3. 3. Tandatangani Dokumen dan Buat QR Code

    Jalankan perintah berikut pada berkas dokumen yang akan disahkan. Secara default, sign memakai signing.key di direktori kerja dan membungkus token ke URL validator resmi.

    sign sign --file surat.pdf --issuer "Prodi D4TI ULBI" --signer "RMA" --doc-id "SK-2026-001" --subject "Surat Keterangan" --footer "d4if-ulbi-2026" --out signature-qr.svg
    --key
    Path kunci privat atau env PASETO_SECRET_KEY (default: signing.key).
    --out
    Keluaran QR Code dalam format .svg, .png, atau .txt.
    --ttl
    Masa berlaku opsional, misalnya 30m, 24h, atau 365d (default permanen).
    --token-out
    Menyimpan string token mentah v4.public.* ke berkas teks untuk arsip.

  4. 4. Sematkan QR ke Dokumen dan Uji Validasi

    Tempelkan berkas signature-qr.svg atau signature-qr.png ke dokumen sebelum diedarkan. Saat dipindai kamera ponsel, QR langsung membuka halaman Validator QR dan memverifikasi tanda tangan secara otomatis. Untuk pemeriksaan dari terminal:

    sign verify --public-key verifying.key --token signature.paseto --file surat.pdf
